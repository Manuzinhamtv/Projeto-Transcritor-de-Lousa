# Transcritor de Lousa e Slides com Inteligência Artificial

Sistema web para transcrição de mídias didáticas (lousa, quadros e slides) com geração de texto alternativo estruturado por IA, focado na acessibilidade de alunos cegos ou com baixa visão.

## Sobre o Projeto

O professor realiza o upload de imagens de conteúdos pedagógicos complexos (esquemas, tópicos, gráficos ou anotações manuais) e a inteligência artificial converte e organiza essas mídias em texto estruturado de forma lógica e semântica. O resultado permite que leitores de tela consumam o conteúdo perfeitamente, garantindo a inclusão escolar.

## Stack

* **Frontend:** React + Tailwind CSS
* **Backend:** Node.js + Express
* **Banco de dados:** SQLite
* **Autenticação:** JWT
* **IA:** Gemini 1.5 Flash (Google AI Studio)

## Pré-requisitos

* Node.js 18+
